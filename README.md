# franchiseki-catalog

FranchiseKI static catalog — franchise brands with FDD-sourced fees, investment ranges,
Item 12 territory rules, and Item 20 state-by-state outlet maps. Pure static site
(generated); deployed to Vercel. Data assembled from each brand's Franchise Disclosure
Document. Availability is exclusion-based: the catalog states what the FDD says and
where units exist; it never claims a specific area is available.
